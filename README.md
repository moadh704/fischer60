# Fischer60

Beautiful interactive website for all **60 games** from Bobby Fischer's classic book *My 60 Memorable Games*.

Live board, move navigation, search, auto-play, and a clean dark premium UI.

## Features

- All 60 games with authentic titles (where available)
- Interactive chessboard (react-chessboard)
- Clickable move list + keyboard-friendly controls
- Auto-play
- Flip board
- Search by player, year, title, ECO
- Fully responsive

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Tech

- Vite + React + TypeScript
- Tailwind CSS
- chess.js
- react-chessboard

## Data

PGN sourced from public collections of the games in *My 60 Memorable Games*.  
Moves are public domain. Annotations from the book are not included (copyrighted).
